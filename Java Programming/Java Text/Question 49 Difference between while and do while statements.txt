Question 49 Difference between while and do while statements

The do…while iteration statement is similar to the while statement. 
A while tests itsloop-continuation condition at the beginning of the loop, 
before executing the loop’s body;
if the condition is false, the body never executes. 
A do…while tests its loop-continuation condition after executing the loop’s body; 
therefore, the body always executes at least once.
When a do…while statement terminates, execution continues with the 
next statement in sequence.
